🔌 Chiamate alle API — Documentazione

Questo documento elenca tutte le API di Google utilizzate nell'app, specifica dove e quando vengono chiamate, e fornisce un flusso di interazione standard con le rispettive chiamate API indicate.

1. Elenco delle API Utilizzate

API File che la chiama Quando viene chiamata
Places Autocomplete places_service.dart Ogni volta che l'utente digita (dopo debounce 300ms, se ≥ 3 caratteri)
Places Details places_service.dart Quando l'utente seleziona un suggerimento dall'autocomplete
Directions directions_service.dart Quando si calcola un percorso (iniziale o ricalcolo per deviazione)
Roads (Nearest Roads) roads_service.dart Quando l'utente è fermo (velocità zero per 10s) per rilevare strade laterali

2. Dettaglio di Ogni API

📍 Places Autocomplete API

GET https://maps.googleapis.com/maps/api/place/autocomplete/json

Parametro Valore Descrizione
input testo digitato Query di ricerca (min. 3 caratteri)
key API_KEY Chiave API Google
language it Risultati in italiano
sessiontoken UUID v4 Raggruppa richieste in una sessione

Dove: PlacesService.getAutocompleteSuggestions()
Quando: Dopo debounce (300ms) e se input.length ≥ 3
Risposta: Array di predictions con description e place_id

📋 Places Details API

GET https://maps.googleapis.com/maps/api/place/details/json

Parametro Valore Descrizione
place_id ID del suggerimento Identificatore univoco del luogo
key API_KEY Chiave API Google
language it Risultati in italiano
fields geometry,name,formatted_address Solo campi necessari (ottimizzazione costi)
sessiontoken UUID v4 Stesso token dell'autocomplete

Dove: PlacesService.getPlaceDetails()
Quando: L'utente seleziona un suggerimento dall'autocomplete
Risposta: geometry.location.lat, geometry.location.lng, name, formatted_address

🗺️ Directions API

GET https://maps.googleapis.com/maps/api/directions/json

Parametro Valore Descrizione
origin lat,lng GPS Posizione corrente del dispositivo
destination lat,lng destinazione Coordinate della destinazione
alternatives true Richiede percorsi alternativi
key API_KEY Chiave API Google
language it Indicazioni in italiano

Dove: DirectionsService.getDirectionsWithAlternatives()
Quando:
  • Alla selezione della destinazione (calcolo iniziale)
  • Quando l'utente devia dal percorso e nessun alternativo è compatibile (ricalcolo)
Risposta: Array di routes con steps, polyline e durata

🛣️ Roads API (Nearest Roads)

GET https://roads.googleapis.com/v1/nearestRoads

Parametro Valore Descrizione
points punti laterali calcolati Punti a 10m dal centro, a 90° rispetto alla direzione
key API_KEY Chiave API Google

Dove: RoadsService.findNearestRoads()
Quando: L'utente è fermo per 10 secondi e non si trova su un waypoint di svolta
Risposta: Array di strade vicine ai punti laterali

3. Flusso di Interazione Standard con Chiamate API

Di seguito il flusso completo di un'interazione tipica, con indicazione esatta di ogni chiamata API effettuata.

Scenario: L'utente cerca "Colosseo" e avvia la navigazione

1 L'utente apre l'app NESSUNA API

Il GPS si attiva. La mappa mostra la posizione corrente.

↓
2 L'utente digita "Co" NESSUNA API

Solo 2 caratteri → filtro minimo non superato. Nessuna chiamata.

↓
3 L'utente digita "Col" TIMER AVVIATO

3 caratteri → debounce 300ms avviato. Non ancora inviata alcuna richiesta.

↓
4 L'utente digita "Colo" (dopo 100ms) TIMER RESETTATO

Timer precedente cancellato, nuovo timer 300ms da "Colo".

↓
5 L'utente digita "Colos" (dopo 80ms) TIMER RESETTATO

Timer precedente cancellato, nuovo timer 300ms da "Colos".

↓
6 300ms senza digitazione PLACES AUTOCOMPLETE

Timer scaduto → prima chiamata API della sessione.
GET /place/autocomplete/json?input=Colos&sessiontoken=abc-123&key=...&language=it
Genera un nuovo sessionToken (UUID v4) per questa sessione di ricerca.
Risposta: ["Colosseo, Roma", "Colosseo Metro, Roma", "Via del Colosseo, Roma", ...]

↓
7 Suggerimenti visualizzati NESSUNA API

La lista appare sotto il campo di testo con i risultati dell'autocomplete.

↓
8 L'utente tocca "Colosseo, Roma" PLACES DETAILS

Usa il place_id del suggerimento con lo stesso sessionToken.
GET /place/details/json?place_id=ChIJ...&sessiontoken=abc-123&fields=geometry,name,formatted_address&key=...
Risposta: lat=41.8902, lng=12.4922, name="Colosseo"
→ Sessione terminata. Nuovo token generato per la prossima ricerca.

↓
9 Calcolo percorso DIRECTIONS API

Origine: posizione GPS corrente. Destinazione: 41.8902, 12.4922
GET /directions/json?origin=41.90,12.50&destination=41.8902,12.4922&alternatives=true&key=...&language=it
Risposta: 3 percorsi. Il più veloce (12 min) selezionato come attivo. Tutti salvati in memoria.

↓
10 Navigazione avviata TIMER 2s ATTIVATO

Polyline disegnata. Lista indicazioni visualizzata. Timer di monitoraggio ogni 2 secondi avviato.

↓
11 Tick 2s — l'utente è sul percorso NESSUNA API

isOnRoute() → distanza dalla polyline ≤ 40m → OK, nessuna azione.

↓
12 Tick 2s — deviazione rilevata! CHECK ALTERNATIVI

Distanza dalla polyline attiva > 40m.
Controlla i percorsi alternativi salvati: l'utente è entro 40m dall'alternativo #2.
Switch istantaneo al percorso #2. Nessuna chiamata API!

↓
13 Tick 2s — deviazione senza alternativo DIRECTIONS API

L'utente è a > 40m da tutti i percorsi → ricalcolo necessario.
GET /directions/json?origin=41.89,12.49&destination=41.8902,12.4922&alternatives=true&key=...
Nuovi percorsi calcolati. Il più veloce diventa il percorso attivo.

4. Riepilogo Chiamate nel Flusso Standard

✅ Bilancio chiamate per una navigazione tipica:
Fase API N° Chiamate Note
Ricerca "Colos" Autocomplete 1 Grazie a debounce + min 3 chars
Selezione suggerimento Details 1 Raggruppata con session token
Calcolo percorso Directions 1 Include alternatives
Navigazione (10 min) — 0 Solo controlli locali ogni 2s
Deviazione su alternativo — 0 Switch locale, nessuna API
Deviazione senza alternativo Directions 1 Solo se necessario
TOTALE (caso tipico) 3 Autocomplete + Details + Directions

5. Dove NON Vengono Fatte Chiamate API

Situazione Motivo
Digitazione con < 3 caratteri Filtro minimo: risultati troppo generici
Digitazione rapida (tra un debounce e l'altro) Timer 300ms non ancora scaduto
Tap su punto generico della mappa Coordinate disponibili direttamente, no place_id
Check posizione ogni 2s (se sul percorso) Calcolo geometrico locale con isOnRoute()
Switch su percorso alternativo I percorsi alternativi sono già in memoria
